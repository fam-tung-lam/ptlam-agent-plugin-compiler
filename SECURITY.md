# Security policy

## Supported versions

Security fixes are provided for the latest stable version published to npm.
Older stable versions and prerelease versions are not supported; upgrade to the
latest stable version before requesting a fix.

| Release                   | Security updates |
| ------------------------- | ---------------- |
| Latest stable npm release | Yes              |
| Older stable releases     | No               |
| Prerelease versions       | No               |

## Report a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/fam-tung-lam/ptlam-agent-plugin-compiler/security/advisories/new).
Do not include vulnerability details in a public issue, discussion, or pull
request.

Include the affected version, impact, reproduction steps or a proof of concept,
and any suggested mitigation. Do not include credentials, tokens, or unrelated
personal data.

The maintainer will coordinate validation, remediation, and disclosure through
the private advisory. If GitHub does not show the private report form, open a
detail-free issue asking the repository owner for a private contact route.
