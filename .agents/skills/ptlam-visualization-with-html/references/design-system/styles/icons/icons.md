# Icons

Use simple, recognizable symbols with a consistent optical size, stroke or fill
treatment, and baseline. Pair unfamiliar icons with visible text. Every
icon-only button needs an accessible name; decorative icons are hidden from
assistive technology.

Icons in this expressive system use clear filled or outlined contrast plus shape
or rotation changes to explain state, such as a split-button menu opening.
Preserve the same end state under reduced motion.

- Use outlined symbols for dense interfaces and filled symbols for selected
  state or a deliberately stronger visual voice.
- Use a 20 CSS pixel icon in dense desktop layouts and 24 pixels by default.
  Keep the interactive target at least 40 pixels for a 20-pixel icon and 48
  pixels for a 24-pixel icon.
- Pair icons smaller than 20 pixels with visible text unless their meaning is
  universally clear in context.
- Keep one outlined, rounded, or sharp family and one consistent weight. When
  using an icon beside text, align optical baselines rather than geometric
  boxes.
- Test symbols for cultural and language ambiguity; use literal text when the
  icon would need explanation.

Material Symbols offers weight, fill, grade, and optical-size axes, but the
artifact must embed its icon paths or text. Do not add an external font or icon
runtime.
