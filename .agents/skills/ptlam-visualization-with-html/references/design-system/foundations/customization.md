# Customization

Start from semantic roles, then adapt color, type, shape, motion, and imagery to
the subject or product brand. Never change a role's meaning merely to obtain a
more decorative result.

Keep component anatomy, states, accessible names, and target sizes stable while
customizing visual expression. Map brand key colors into primary, secondary,
tertiary, neutral, and neutral-variant groups; derive `on-*` and container roles
instead of choosing each color independently. Preserve a complete fallback
theme when user-generated or dynamic color is unavailable.

Source snapshot: Material 3 customization guidance, captured with Firecrawl on
2026-08-07.
