# Platform adaptation

Use the portable HTML baseline for pointer, keyboard, touch, and assistive
technology.

For a watch-sized surface, adapt to round screens with edge-aware containment,
short readable paths, large reachable controls, and a type scale designed for
glanceable content. Treat shape morphing and spring motion as feedback, never as
the only state indicator.

For a spatial or XR surface, group content on spatial panels, keep the primary
content near the center of the field of view, support seated and standing use,
minimize motion sickness and strain, and support multimodal input. Use at least
a 56 CSS pixel target for icon controls in an XR-targeted simulation.

Do not claim a platform-specific Material component is implemented on the web
merely because its visual appearance can be reproduced in HTML.

Source snapshot: Material 3 watch and XR foundation guidance, captured with
Firecrawl on 2026-08-07.
