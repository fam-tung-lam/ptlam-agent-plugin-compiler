# Designing

Build each screen from elements, structure, and flow. Make boundaries,
relationships, hierarchy, reading order, and transitions visible before tuning
the expressive intensity.

Use expressive emphasis to reveal the most important action or state, not to
make every region compete.

Use semantic HTML order, landmarks, and one sequential heading hierarchy to
express structure before adding ARIA. Give custom interactive elements a native
equivalent whenever possible; otherwise provide a concise role and label.
Preserve the browser's default tab order, define initial focus only when the
flow needs it, and return focus to the initiating control after dismissing a
temporary surface.
