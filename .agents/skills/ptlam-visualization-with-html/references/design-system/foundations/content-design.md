# Content design

Use short labels that name the actor, action, state, or result. Put explanatory
text beside the visual element it qualifies. Keep notifications actionable and
write alt text for the purpose of the visual, not its pixel inventory.

Translate meaning rather than sentence structure. Avoid idioms in controls and
labels that must survive localization. Follow a consistent editorial style.

Describe an informative image by its purpose and context, normally within 125
characters. Do not start with "image of" or inventory pixels. Give decorative
images `alt=""`. Put essential facts in adjacent text when a caption or diagram
label communicates more clearly than alt text alone.
