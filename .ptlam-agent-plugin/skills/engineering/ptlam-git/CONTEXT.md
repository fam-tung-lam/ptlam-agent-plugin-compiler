# Project Git Context

## Git preferences

- Start the description in Conventional Commit subjects with a lowercase verb,
  and use the same casing in matching pull request titles. For example:
  `ci(release): avoid attestation race`. This overrides the portable default to
  capitalize the description. Evidence: direct user instruction on 2026-08-10.
